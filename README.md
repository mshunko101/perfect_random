# Общая архитектура ГСЧ

## Компоненты

- **Ассоциативность** (цепляется к прошлому)
- **Среднее значение** (Опыт)
- **Уникальное значение** (Смысл)

### Итог: Время


# Уязвимости:

*Критический фактор* - по своей природе ГСЧ может быть уязвим к периоду генерации случайного значения: период между генерациями - критический фактор.

*Форс-мажор* - исходя из принципов моей сумашедшей науки, энтропия и неупорядоченность (каскадный процесс) может упорядочится в некоторый момент времени, в некоторой области - это фактор форс-мажор для криптографии и ЭЦП.


**Идеальный период** исходя из [[0]](https://github.com/mshunko101/science/blob/2d7a91c65a2b94da1472e1027431f039ae58ca19/2.%20%D0%9C%D0%9E%D0%9D%D0%9E%D0%93%D0%A0%D0%90%D0%A4%D0%98%D0%AF/%D0%A7%D0%95%D0%A0%D0%9D%D0%9E%D0%92%D0%98%D0%9A%D0%98/%D0%A2_%D0%90%D0%94%D0%90.md) идеальный период ГСЧ зависит **внезапно** от средней продолжительности жизни на Земле, на форме этот параметр [**ОПЖ**](https://ru.wikipedia.org/wiki/Ожидаемая_продолжительность_жизни)[(**LE**)](https://en.wikipedia.org/wiki/Life_expectancy).<br>
