# Техническая документация: Параметр period ГПСЧ perfect_random
## и мониторинг каскадной устойчивости популяций

**Автор:** Шунько Михаил Геннадьевич  
**Дата:** 2026-09-17  
**Версия:** 1.0

---

## 1. Постановка задачи

Параметр `period` генератора псевдослучайных чисел perfect_random 
определяется на основе глобальной ожидаемой продолжительности жизни 
при рождении (ОПЖ, данные ООН, World Population Prospects).

ОПЖ — динамическая величина (73,8 лет на 2026 год, прогноз роста до 
81,5 к 2100). Для обеспечения устойчивости генератора при изменении 
ОПЖ разработана модель, связывающая `period` со структурными 
свойствами каскадной динамики.

## 2. Каскадные константы

| Параметр | Значение | Источник |
|----------|----------|----------|
| Фикс-поинт | b* = 4/9 | Каскадное отображение |
| Производная | \|f'(b*)\| ≈ 0,874 | (2/3)·(9/4)^(1/3) |
| Скорость роста | k = 0,1352 | -ln\|f'(b*)\| |
| Предел связей | 49 = 7² | (43 + 55) / 2 |
| ζ-порог 95% | 50,4 года | Логистическая модель |
| ζ-порог 99% | 62,6 года | Логистическая модель |

---

## 3. Логистическая модель связей

Число связей, нарабатываемых каскадом к возрасту t:

k(t) = 49 / (1 + 48 · e^(-0,1352·t))

Параметр k = 0,1352 выведен из каскадной динамики (через 
производную в фикс-поинте), а не подобран. Сходимость с 
эмпирическими оценками автора:

| Возраст | Оценка автора | Модель |
|---------|---------------|--------|
| 12 лет  | 5 связей      | 4,7   |
| 25 лет  | 19 связей     | 18,6  |
| 50 лет  | 47 связей     | 47,0  |
| 73,8    | 49 связей     | 48,9  |

---

## 4. Эффективный ζ для популяции

ζ_эфф = Σ wi · k(ti)

где:
- wi — доля возрастной группы i в популяции
- ti — средний возраст группы i
- k(ti) — число связей по логистической модели

ζ_эфф ≤ 49 (структурный предел каскада)

---

## 5. Пороговые значения для мониторинга

| ζ_эфф | Статус | Интерпретация |
|-------|--------|---------------|
| < 20  | КРИТИЧНО | Каскад не компенсирует возмущения |
| 20-25 | ОПАСНО | Необходимы срочные меры поддержки |
| 25-30 | РИСК | Усилить меры поддержки |
| 30-35 | НОРМА | Регулярный мониторинг |
| 35-40 | ХОРОШО | Устойчивое состояние |
| > 40  | ОПТИМУМ | Полный запас прочности |
| → 49  | НАСЫЩЕНИЕ | Предел структуры 7×7 |

## 8. Протокол ежегодного мониторинга

### 8.1. Источники данных

1. **Белстат** (belstat.gov.by): численность по 5-летним 
   возрастным группам на 1 января
2. **ООН** (population.un.org): World Population Prospects, 
   годовой отчёт
3. **Fund for Peace** (fundforpeace.org): Fragile States Index

### 8.2. Алгоритм обновления

Шаг 1: Получить данные по возрастным группам (5-летние)
Шаг 2: Вычислить ζ_эфф = Σ wi · k(ti)
Шаг 3: Сравнить с пороговыми значениями
Шаг 4: Если ζ_эфф < 25 — рекомендовать усиление мер поддержки
Шаг 5: Обновить period ГПСЧ = текущая ОПЖ (если > 62,6)

### 8.3. Принятие решений

| Изменение ζ_эфф | Действие |
|-----------------|----------|
| Рост | Устойчивость улучшается, меры можно ослабить |
| Стагнация 30-35 | Мониторинг, без вмешательства |
| Падение < 30 | Усилить меры поддержки |
| Падение < 25 | Срочные меры: демография, здравоохранение |
| Падение < 20 | Критическая зона: реальная угроза стабильности |

## 9. Определение period для ГПСЧ

period = max(ОПЖ_текущая, ζ_порог_99)

Где:
- ОПЖ_текущая — глобальная ОПЖ по данным ООН (73,8 на 2026)
- ζ_порог_99 = 62,6 — минимальный period для 99% заполнения

При period ≥ 62,6 каскад насыщен до 49 связей.
При period ≥ 73,8 — насыщение 99,8%.

Воспроизводимость: значение period записывается в структуру 
состояния генератора вместе с seed.
