# MSHUNKO RNG — Трёхкаскадный генератор псевдослучайных чисел

**TL;DR:** Генератор построен на принципе каскадной динамики — три структурно различных модуля последовательно разрушают паттерны друг друга. Ни один компонент по отдельности не идеален, но в каскаде на выходе не остаётся статистических артефактов, detectable тестами Dieharder.

---

## Метафора

Представьте водопад из трёх порогов. На каждом пороге вода перемешивается по-своему. Ни один порог не создаёт идеальную турбулентность — у каждого есть застойные зоны и ламинарные участки. Но к подножию приходит поток, в котором от недостатков каждого порога не осталось следа, потому что **каждый следующий порог ломает паттерны предыдущего**.

Этот ГСЧ — такой водопад.

---

```
│ Associativity │     │              │     │              │

│  (LCG-ядро)  │     │  (MT19937 +  │     │ (коллизионное│
│              │     │ нормализация)│     │ перемешивание)│
└──────────────┘     └──────────────┘     └──────────────┘
       │                                           │
       │              ┌──────────────┐             │
       └─────────────▶│ RotationCalc │◀────────────┘
                      │  (сброс по   │
                      │  периоду)    │
                      └──────────────┘
```

## Каскады

### Каскад 1 — AssociativityCore (сырой поток)

**Алгоритм:** LCG — `seed = (seed * 1103515245 + 12345) % UINT_MAX`

| Свойство | Оценка |
|---|---|
| Скорость | Высокая |
| Равномерность покрытия | Хорошая |
| Структурный недостаток | Решётчатая структура — точки ложатся на гиперплоскости в многомерном пространстве |

Одиночный LCG не проходит Dieharder: решётка детектируется мгновенно. Но LCG даёт быстрый, плотный, равномерный поток — **сырую воду**, которая поступает на следующий порог.

---

### Каскад 2 — MeanCore (размывание решётки)

**Алгоритм:** нормализация LCG-выхода в `[0, 1]` + шум от MT19937 с амплитудой `0.1`

```
adjusted = (base / UINT_MAX) * mean + uniform(0, 1) * 0.1
```

| Свойство | Оценка |
|---|---|
| Источник шума | MT19937 (период `2^19937 - 1`, проходит Dieharder самостоятельно) |
| Амплитуда шума | 0.1 — мала относительно основного сигнала |
| Структурный эффект | Размытие гиперплоскостей LCG |

Шум MT19937 не коррелирован с LCG-потоком, поэтому точки, лежавшие на гиперплоскостях, сдвигаются на случайные величины. Решётчатая структура, которую ищет Dieharder, **исчезает**.

Первый порог водопада: ламинарный поток LCG встречает турбулентность MT19937.

---

### Каскад 3 — FantasyCore (коллизионное перемешивание)

**Алгоритм:**

1. При коллизии (повтор значения) сравниваются биты столкнувшихся чисел.
2. Различающиеся биты становятся **размерностями** — парами поправок `{0, 1}` или `{1, 0}`.
3. `apply_fantasy()` добавляет `±0.01` по каждой размерности со случайным выбором знака через MT19937.

| Свойство | Оценка |
|---|---|
| Топливо | Сам факт обнаружения коллизии — слабости потока |
| Рост перемешивания | Чем больше коллизий обработано, тем больше размерностей и сильнее отклонение от LCG-структуры |
| Непредсказуемость знака | Случайный выбор через MT19937 делает поправки непредсказуемыми даже при известных размерностях |

Третий порог: водопад сам обнаруживает застойные зоны и направляет туда дополнительные струи. Коллизии — это места, где детерминированная природа LCG проступает наружу. FantasyCore **использует обнаружение слабости как источник нового перемешивания**.

---

## Динамический сброс — RotationCalculator

Вычисляет период вращения по трём точкам A, B, O_okr:

```
OA = A - O_okr
OB = B - O_okr
cos(θ) = (OA · OB) / (|OA| · |OB|)
θ = arccos(cos(θ))
ω = θ / time_AB
T = 2π / ω
```

Период (в годах) переводится в количество 8-байтовых блоков:

```
inc_max = round(T * 365.25 * 24 * 3600 / 8)
```

После `inc_max` сгенерированных байтов весь генератор пересоздаётся с новым seed из `time(nullptr)`.

**Роль:** обрыв длиннопериодных корреляций. Даже если в глубине каскада накопились медленные паттерны (растущие размерности FantasyCore, заполнение истории), сброс обнуляет их до того, как они станут статистически заметными.

## Защита от коллизий

| Параметр | Значение | Назначение |
|---|---|---|
| `MAX_RETRIES` | 49 | Максимальное число попыток перегенерации при коллизии |
| `MAX_HISTORY_SIZE` | 49 | Максимальный размер буфера истории |
| `history` | `unordered_set` | Буфер уже выданных значений |

**Логика:**

- **Коллизия** → перегенерация (до 49 попыток) + регистрация размерностей в FantasyCore.
- **Переполнение истории** → полная очистка + сброс FantasyCore.
- **Исчерпание попыток** → пересоздание всех ядер с новым seed.

Число 49 — компромисс: окно достаточно короткое, чтобы коллизии в нём редки (пространство `2^32` велико), но достаточно длинное, чтобы FantasyCore успел накопить несколько размерностей для перемешивания.

## Почему каскад маскирует слабости

Ключевой принцип: **уровни слабости не совпадают**.

| Уровень | Его слабость | Что её маскирует |
|---|---|---|
| LCG | Решётчатая структура, короткий период | Шум MT19937 размывает решётку |
| MeanCore | Амплитуда шума всего 0.1 | FantasyCore накапливает поправки до `±0.01 × n_dim` |
| FantasyCore | Поправки крошечные и детерминированные | Случайный выбор знака через MT19937 |
| Все вместе | Возможны длинные корреляции | Периодический сброс по RotationCalculator обрывает их |

Dieharder ищет статистические паттерны: корреляции, решётки, отклонения распределений. Каждый каскад уничтожает один тип паттерна, и к выходу не остаётся ни одного, достаточно выраженного, чтобы тест его поймал.

## Оценка качества

| Критерий | Результат |
|---|---|
| Dieharder | Проходит |
| Статистическая чистота | Высокая — пригоден для Monte Carlo, симуляций, игр |
| Криптостойкость | **Нет** — состояние LCG и MT19937 восстанавливается по выходным значениям |
| Аппаратная случайность | **Нет** — полностью детерминированный программный ГСЧ |

> Каскад скрывает паттерны от статистических тестов, но не от обратной инженерии. Для криптографии используйте /dev/urandom или аппаратные источники энтропии.

## Использование

```cpp
#include "mshunko_rng.h"

// Создание генератора с seed и периодом (в условных годах)
RNG rng(12345, 7.5);

// Генерация
for (size_t i = 0; i < 1000; ++i) {
    double value = rng.generate(8);  // 8 байт за вызов
}

// Сброс
rng.reset();
```
